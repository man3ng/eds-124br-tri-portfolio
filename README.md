# EDS 124BR Tri Portfolio

This repository contains coursework and project artifacts for EDS 124BR.

## Overview

The goal of this portfolio is to collect and organize work completed throughout the course in a single, version-controlled location.

## Repository Structure

At the moment, this repository is being set up and will be expanded with portfolio content over time.

## Getting Started

To work with this repository locally:

1. Clone the repository.
2. Open it in your editor of choice.
3. Add or update portfolio artifacts and commit changes.
